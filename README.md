# CPU Scheduling Simulator - Group YWAV

## 📌 Project Description
This project is a CPU Scheduling Simulator implemented in Python. It reads process data from an external text file (`input.txt`) and simulates two scheduling algorithms:
1. **FCFS** (First-Come, First-Served)
2. **Round Robin** (with Quantum = 3)

The program calculates Waiting Time, Turnaround Time, and Response Time for each process, generates a Gantt Chart, and provides a final comparison between the two algorithms.

## 📂 Input File Format
The program reads from `input.txt`. Each line should contain: `<Process_Name> <Arrival_Time> <Burst_Time> <Priority>`
Example:
P1 0 2 2
P2 1 5 2

## 🚀 How to Run
1. Make sure you have Python installed.
2. Clone this repository.
3. Ensure `input.txt` is in the same folder as `main.py`.
